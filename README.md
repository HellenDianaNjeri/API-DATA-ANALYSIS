# Understanding APIs as a Beginner  
### Collecting and Analyzing Real-World Data Using Public APIs

## Project Overview
This project explores how **APIs (Application Programming Interfaces)** are used as real-world data sources in data science and AI workflows. Unlike static datasets (such as CSV files), APIs provide **dynamic, live data** that can be accessed programmatically.

The project demonstrates how to fetch data from a public API using Python, clean and transform the data, perform exploratory data analysis (EDA), and generate insights through visualizations. An optional analytical or predictive component is included to introduce beginner-level AI concepts.

---

##  Objective
The main objective of this project is to build foundational skills in:
- Understanding how APIs work
- Fetching live data using Python
- Converting JSON responses into structured datasets
- Cleaning and analyzing real-world data
- Performing exploratory data analysis (EDA)
- Communicating insights clearly through visualizations

---

## Problem Statement
Many beginner data science learners work exclusively with static datasets and lack exposure to live data pipelines. This limits their understanding of how data is accessed and processed in real-world AI and analytics systems.  
This project bridges that gap by introducing APIs as dynamic data sources.

---

##  Why This Project Matters
APIs are the primary way data scientists and AI engineers access real-time data in production systems, dashboards, and machine learning applications. Understanding how to work with APIs is a critical industry skill.  
This project demonstrates practical experience in integrating APIs into a complete data science workflow.

##  Setup & Execution

### 1. Install Required Libraries
```bash
pip install pandas numpy matplotlib seaborn requests
```
### 2. Obtain API Credentials
```
If required, sign up on the selected API’s website and generate an API key.
```
### 3. Clone the Repository
```
git clone https://github.com/HellenDianaNjeri/API-DATA-ANALYSIS.git
cd API-DATA-ANALYSIS
```
### 4. Run the Notebook

Open the Jupyter Notebook

Execute cells sequentially from top to bottom

Ensure API credentials are stored securely (not hard-coded)
